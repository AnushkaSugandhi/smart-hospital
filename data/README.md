# Sample data

- `test_hospital_data.csv` — required columns only (the original format still works).
- `sample_full_upload.csv` — every required and optional column (ventilators, theatres, nurses, oxygen, blood by group).

Upload either file on the **Data Upload** page. The column reference is in the main README and on that page.
The seed data used on first start is generated by `backend/app/seed/generate_data.py`.
